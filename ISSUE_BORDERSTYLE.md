# Bug: Storybook fails with "BorderStyle not exported from wasm.js"

## Summary

When running Storybook locally (`npm run storybook`), the Workbook component fails to render with the error:

```
SyntaxError: The requested module '/@fs/C:/project/IronCalc/bindings/wasm/pkg/wasm.js' 
does not provide an export named 'BorderStyle'
```

## Environment

- OS: Windows 11
- Node: v22.x
- Storybook: v10.0.7
- wasm-pack: 0.13.1

## Reproduction Steps

1. Clone the repository
2. Build WASM: `cd bindings/wasm && wasm-pack build --target web`
3. Install webapp deps: `cd webapp/IronCalc && npm install`
4. Run Storybook: `npm run storybook`
5. Open http://localhost:6006/?path=/story/example-workbook--primary
6. Error appears

## Root Cause

The webapp imports `BorderStyle`, `BorderType`, and `BorderOptions` from `@ironcalc/wasm`:

```typescript
// webapp/IronCalc/src/components/BorderPicker/BorderPicker.tsx:1
import { type BorderOptions, BorderStyle, BorderType } from "@ironcalc/wasm";
```

However, these types are defined in `bindings/wasm/types.ts`, which is NOT included in the generated `pkg/` folder by `wasm-pack`.

The `pkg/wasm.js` file is auto-generated and doesn't include TypeScript enums/types from `types.ts`.

## Current `types.ts` Location

```
bindings/wasm/types.ts  ← manually written types
bindings/wasm/pkg/      ← generated by wasm-pack (missing types.ts!)
  ├── wasm.js
  ├── wasm.d.ts
  └── wasm_bg.wasm
```

## Proposed Fix

**Option A: Update Makefile to copy types**

Add to `bindings/wasm/Makefile`:
```makefile
build:
	wasm-pack build --target web
	cp types.ts pkg/
	npx tsc --module ESNext --declaration pkg/types.ts --outDir pkg/
```

**Option B: Re-export types from wasm.js**

Create `bindings/wasm/pkg/index.js` that re-exports both `wasm.js` and compiled `types.js`.

**Option C: Change webapp imports**

Update webapp to import types from a separate path:
```typescript
import { BorderStyle, BorderType } from "@ironcalc/wasm/types";
```

## Affected Files

- `bindings/wasm/types.ts` - defines BorderStyle, BorderType, BorderOptions, etc.
- `bindings/wasm/Makefile` - build script
- `webapp/IronCalc/src/components/BorderPicker/BorderPicker.tsx` - imports from @ironcalc/wasm
